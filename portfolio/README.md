# 🚀 Portfólio — Gustavo, Desenvolvedor Web

Site portfólio profissional para mostrar seu trabalho como desenvolvedor de sites para negócios locais.

## ✨ Funcionalidades

- **Design premium** com gradientes animados e orbes flutuantes
- **Animações suaves** (scroll reveal, hover effects, transições)
- **WhatsApp integrado** em 3 pontos estratégicos + botão flutuante
- **5 projetos sample** prontos para mostrar
- **Tabela de preços** com 3 planos
- **Depoimentos** de clientes fictícios
- **100% responsivo** — celular, tablet e desktop
- **SEO otimizado** — meta tags, Open Graph
- **Zero dependências** — HTML + CSS + JS puro

## 🚀 Deploy Rápido

### Opção 1: Vercel (recomendado)
1. Crie conta em [vercel.com](https://vercel.com)
2. Instale o CLI: `npm i -g vercel`
3. No diretório do portfolio: `vercel --prod`

### Opção 2: Netlify
1. Crie conta em [netlify.com](https://netlify.com)
2. Arraste a pasta `portfolio/` para o dashboard

### Opção 3: GitHub Pages
1. Crie um repositório: `gustavo-portfolio`
2. Faça push dos arquivos
3. Ative GitHub Pages nas settings

## 🎨 Personalização

Edite apenas o arquivo `js/config.js`:

```javascript
const PORTFOLIO = {
  dev: {
    name: 'Seu Nome',
    // ...
  },
  theme: {
    primary: '#6366f1',  // Cor principal
    // ...
  },
  // ...
};
```
